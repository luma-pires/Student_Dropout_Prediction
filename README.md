# Título
Prevendo a evasão de alunos no Ensino Superior Online

# Resumo
Este projeto analisa dados de uma Instituição de Ensino Superior Online para investigar os fatores que contribuem para o baixo engajamento acadêmico e a consequente evasão de alunos. O trabalho envolve uma análise exploratória detalhada, engenharia de features e modelagem preditiva (Random Forest e Regressão Logística), com o objetivo de identificar padrões e fornecer insights sobre os principais fatores que influenciam a evasão estudantil.
